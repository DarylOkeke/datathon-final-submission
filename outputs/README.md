# Outputs

This folder is regenerated by:

```bash
python run_pipeline.py
```

Key files:

- `forecast_v42_pre_bias.csv`: final interval forecast before competition-specific post-processing bias
- `forecast_v42.csv`: final competition-format submission
- `cv_holdout_metrics.csv`: Apr-May train / June holdout CV model comparison
- `cv_feature_importance.csv`: CV share-model feature importances
