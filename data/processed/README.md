# Processed Data

This folder is regenerated by:

```bash
python run_pipeline.py
```

Key files:

- `daily_clean.csv`: parsed daily sheets for portfolios A-D
- `interval_clean.csv`: parsed interval sheets with 2025 dates and half-hour slot indices
- `august_daily_anchors.csv`: completed August daily anchors after the Portfolio D patch
- `cv_training_layer.csv`: repaired 48-slot CV training layer
- `cv_share_profiles.csv`: historical CV slot-share profiles
- `cct_profiles.csv`: historical CCT intraday profiles
- `abandonment_share_profiles.csv`: historical abandoned-call share profiles
